# Addis Unveiled

A student Internet Programming project introducing the culture, history, food, coffee traditions, attractions, and events of Addis Ababa, Ethiopia.

## Current stage

**Stage 1: HTML5 structure only.** The site uses semantic HTML elements and linked pages. Styling, multimedia, and responsive design will be added in later stages.

## Pages

- `index.html` — homepage and overview
- `places.html` — attractions and places to visit
- `food.html` — Ethiopian food
- `coffee.html` — coffee traditions
- `culture.html` — art, history, and cultural life
- `events.html` — events and activities

## Run locally

Open `index.html` in a web browser. No installation is required.

## Group workflow

1. Agree on tasks before editing.
2. Each member works on an assigned page or a clearly defined improvement.
3. Test links and HTML before committing.
4. Use clear commit messages, such as `Add coffee traditions page`.
5. Pull the latest changes before starting new work.
6. Do not overwrite another member's work without coordinating.

## Future stages

- Add CSS for typography, colors, spacing, and layout.
- Add responsive styling for phones and tablets.
- Add properly credited images and accessible alt text.
- Add video and audio only where they improve the experience.
- Verify factual details, especially event dates and visitor information.
